SLIDE 2: Velocidade

Explique assim:

"O Twitter recebe 6.000 tweets POR SEGUNDO. Não dá tempo de salvar em banco de dados tradicional e depois processar. Tem que processar EM TEMPO REAL."

Exemplo prático: "Quando vocês procuram algo no Google, a resposta vem em 0.2 segundos. Isso é Big Data processando BILHÕES de páginas instantaneamente."

SLIDE 3: Variedade

Explique assim:

"Big Data não é só números em tabelas. São TEXTOS (tweets), IMAGENS (Instagram), VÍDEOS (YouTube), ÁUDIOS (Spotify), SENSORES (carros autônomos)."

SLIDE 4: Veracidade

Explique assim:

"Nem todo dado é confiável. Fake news, bots, sensores com defeito. 30% dos dados podem estar errados!"

SLIDE 5: Valor

Explique assim:

"Ter 1 bilhão de dados não adianta NADA se você não extrair INSIGHTS. O objetivo é transformar dados em DECISÕES."

Exemplo prático: "Uber usa Big Data para: prever demanda, definir preço dinâmico, otimizar rotas, identificar motoristas problemáticos."

🔧 PROBLEMAS COMUNS E SOLUÇÕES

❌ Problema 1: VirtualBox não abre

Sintoma: Mensagem "VirtualBox kernel driver not loaded"

Causa: Virtualização desabilitada na BIOS

Solução:

  1. Reiniciar computador
  2. Entrar na BIOS (geralmente F2, F10 ou Del durante boot)
  3. Procurar: "Intel VT-x" ou "AMD-V"
  4. Habilitar (Enabled)
  5. Salvar e sair (F10)

Se não puder mexer na BIOS: Use outra máquina do lab

❌ Problema 2: VM muito lenta

Causa: RAM ou CPUs insuficientes

Solução:

  1. Desligue a VM (fechar janela → "Desligar máquina")
  2. Configurações → Sistema
  3. Reduzir RAM para 2048 MB se necessário
  4. Processador → 1 CPU apenas

❌ Problema 3: Erro ao carregar ISO

Sintoma: "FATAL: Could not read from boot medium"

Solução:

  1. Certifique-se que o caminho da ISO está correto
  2. Verifique se arquivo ISO não está corrompido (tamanho ~4GB)
  3. Re-baixe ISO se necessário

❌ Problema 4: Sem internet na VM

Teste: Abrir Firefox na VM, acessar google.com

Solução:

  1. Desligue VM
  2. Configurações → Rede
  3. Placa 1: Conectada a "NAT"
  4. ☑️ Cabo conectado (marcar)
  5. OK e ligar VM novamente

❌ Problema 5: Instalação travou/congelou

Espere: Mínimo 45 minutos antes de considerar travado

Se realmente travou:

  1. Fechar janela VM → "Desligar máquina"
  2. Excluir VM
  3. Recomeçar do zero (é rápido da segunda vez)

🔧 PROBLEMAS COMUNS E SOLUÇÕES

❌ Problema: Comando não encontrado

Causa: PATH não configurado ou software não instalado

Solução:

  1. Verifique se software está instalado: which nome_comando
  2. Se não estiver, reinstale conforme instruções de preparação
  3. Verifique variáveis de ambiente: echo $PATH
  4. Recarregue: source ~/.bashrc

❌ Problema: Erro de permissão

Sintoma: "Permission denied"

Solução:

  1. Verifique propriedade: ls -la arquivo
  2. Ajuste permissões: chmod +x arquivo
  3. Ou use sudo se necessário: sudo comando

❌ Problema: Processo não inicia

Causa: Porta já em uso ou falta memória

Solução:

  1. Verifique portas: netstat -tulpn | grep PORTA
  2. Mate processo antigo: kill -9 PID
  3. Verifique memória: free -h
  4. Libere memória fechando programas desnecessários
