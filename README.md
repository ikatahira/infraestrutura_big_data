# Infra BigData

## 📋 Descrição do Projeto

Este repositório contém as entregas dos exercícios práticos da disciplina de **Infraestrutura de Big Data**. Cada semana possui exercícios práticos com comandos Linux, Docker, Hadoop, Spark e outras tecnologias do ecossistema Big Data.

## 🎯 Objetivos

- Dominar comandos Linux essenciais para administração de clusters
- Implementar e gerenciar infraestrutura distribuída com Docker e Hadoop
- Desenvolver pipelines de processamento de dados com MapReduce e Spark
- Aplicar conceitos de Data Lakes, HDFS e arquitetura Medallion
- Monitorar recursos e otimizar performance em ambientes distribuídos

## 🧰 Tutorial Git (Adicionar, Commitar e Push para main)

### 1) Verificar status do repositório

```bash
git status
```

### 2) Adicionar alterações

Adicionar tudo:

```bash
git add .
```

Ou adicionar arquivo específico:

```bash
git add README.md
git add "semanas 1/README.md"
```

### 3) Criar commit

```bash
git commit -m "Atualiza entregas das semanas e documentação"
```

### 4) Enviar para a branch main

```bash
git push origin main
```

### 5) Fluxo completo (resumo)

```bash
git status
git add .
git commit -m "Mensagem do commit"
git push origin main
```

### Comandos básicos úteis

```bash
# Ver histórico de commits
git log --oneline

# Ver diferenças antes do commit
git diff

# Ver branch atual
git branch

# Baixar atualizações da main remota
git pull origin main
```
