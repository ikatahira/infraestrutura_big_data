# Infraestrutura para Big Data
## Material Didático Completo - 20 Semanas

### 📚 Sobre este Material

Este pacote contém o material didático completo para a disciplina **Infraestrutura para Big Data** do Curso Superior de Tecnologia em Ciência de Dados, desenvolvido seguindo o mesmo padrão da disciplina de Laboratório de Administração de Sistemas Operacionais de Redes.

### 🎯 Conteúdo de Cada Semana

Cada arquivo de semana (semanas/semanaN.html) contém:

- ✅ **Objetivos de Aprendizagem**: Metas claras para a semana
- ✅ **Conteúdo Programático**: Tópicos detalhados
- ✅ **Vídeos Recomendados**: Links para YouTube com tutoriais
- ✅ **Materiais de Apoio**: PDFs, scripts, datasets, notebooks
- ✅ **Ferramentas Utilizadas**: Tecnologias práticas da semana
- ✅ **Atividades Práticas**: Exercícios hands-on com pontuação

### 📝 Conteúdo de Cada Guia

Cada guia semanal (guias/semanaN_guia.html) contém:

- ✅ **Exercícios Práticos**: 1-2 exercícios detalhados por semana
- ✅ **Rubricas de Avaliação**: Critérios claros (Excelente, Bom, Regular, Insuficiente)
- ✅ **Soluções Comentadas**: Exemplos de código e explicações
- ✅ **Tempo Estimado**: Duração sugerida para cada exercício
- ✅ **Recursos Adicionais**: Links e dicas complementares

### 🚀 Como Usar

1. **Abra o arquivo `index.html`** no navegador para acessar a página principal
2. **Navegue pelas semanas** clicando nos cards de cada semana
3. **Estude o conteúdo** da semana (teoria, vídeos, materiais)
4. **Pratique com o guia** correspondente (exercícios e soluções)
5. **Repita** para as 20 semanas do curso

### 🎓 Projeto Integrador

O curso inclui um **Projeto Integrador** desenvolvido em 3 etapas:

- **Semana 10**: Definição do projeto, arquitetura e proposta
- **Semana 19**: Desenvolvimento e implementação do pipeline
- **Semana 20**: Apresentação final (15-20 minutos + demo)

### 💻 Tecnologias Abordadas

- **Hadoop Ecosystem**: HDFS, MapReduce, YARN
- **Apache Spark**: RDDs, DataFrames, Spark SQL, MLlib
- **Bancos NoSQL**: MongoDB, Cassandra
- **Streaming**: Apache Kafka
- **Cloud**: AWS (S3, EMR, Redshift, QuickSight, Glue, Athena)
- **IoT**: Arduino, ESP32, MQTT
- **Visualização**: QuickSight, Tableau, Python (matplotlib)
- **Linguagens**: Python (PySpark), Java, Scala, SQL, CQL

### 📊 Sistema de Avaliação

Cada semana possui atividades práticas com pontuação. Os guias fornecem rubricas detalhadas com 4 níveis:

- **Excelente**: Implementação completa e otimizada
- **Bom**: Implementação funcional com pequenas melhorias possíveis
- **Regular**: Implementação parcial ou com problemas
- **Insuficiente**: Não atende aos requisitos mínimos
