Plano de Aula Prática: Infraestrutura para Big Data

Fatec Ourinhos - Tecnologia em Ciência de Dados

1. Equipamento de Estudo: Dell PowerEdge T110 II

Este servidor torre é o objeto central para o estudo da camada física e tolerância a falhas.

Especificações Técnicas do Nó:

  • Processador: Intel Xeon E3-1200 (Foco em processamento paralelo)
  • Memória: 8GB DDR3 ECC (Correção de erros em tempo real)
  • Armazenamento: 2TB com Controladora RAID PERC H200
  • Conectividade: Dual Gigabit Ethernet (1GbE)

2. Atividades Práticas Sugeridas

Módulo I: Camada Física e Redes

Atividade Objetivo Pedagógico
Crimpagem de Cabos CAT6 Entender a integridade do sinal e diagnóstico de perdas de pacotes.
Desmontagem do Servidor Identificar componentes críticos: Memória ECC e Controladora RAID.
Teste com iperf3 Validar a largura de banda real entre o servidor e os desktops do laboratório.
Dica de Aula: Use o iperf3 para demonstrar como um cabo mal crimpado reduz a rede de 1000Mbps para 100Mbps, atrasando o processamento de grandes datasets.

3. Conceitos de Big Data Aplicados ao Hardware

  • Escalabilidade Vertical: Demonstrar como a torre permite adicionar mais RAM (até 32GB) e discos.
  • Tolerância a Falhas: Configurar RAID 1 na controladora PERC para simular a queima de um disco sem perda de dados.
  • Data Locality: Discutir por que o processamento deve ocorrer o mais próximo possível do armazenamento SAS/SATA.
