Se você não tem recursos para rodar uma VM ou prefere trabalhar nativamente no Windows, o WSL2 (Windows Subsystem for Linux 2) é uma excelente alternativa. Ele executa um kernel Linux real dentro do Windows com desempenho próximo ao nativo. Você pode instalar o Hadoop, Spark e Kafka normalmente pelo WSL2.
ℹ️ WSL2 vs VirtualBox: O WSL2 integra-se ao Windows (compartilha arquivos facilmente entre os sistemas) e consome menos recursos. A desvantagem é que algumas configurações de rede do Hadoop precisam de ajustes extras. Para uso didático neste semestre, ambos funcionam igualmente bem.
01
Habilitar o WSL2 no Windows
Abra o PowerShell como Administrador (clique direito no menu Iniciar → "Windows PowerShell (Admin)") e execute o comando abaixo. O sistema pode pedir para reiniciar.
powershell — Administrador
# Este comando único faz tudo: habilita WSL, instala WSL2 e instala Ubuntu PS> wsl --install
✅ Saída esperada
Installing: Virtual Machine Platform Virtual Machine Platform has been installed. Installing: Windows Subsystem for Linux Windows Subsystem for Linux has been installed. Installing: Ubuntu Ubuntu has been installed. The requested operation is successful.
⚠️ Se o comando acima instalar Ubuntu 20.04 (versão antiga), force a versão 22.04: wsl --install -d Ubuntu-22.04
02
Verificar a versão do WSL instalada
Confirme que está usando o WSL versão 2 (e não a versão 1, que é mais antiga e tem desempenho inferior).
powershell
# --list = lista as distribuições instaladas # --verbose = mostra detalhes incluindo a versão do WSL PS> wsl --list --verbose
✅ Saída esperada — a coluna VERSION deve ser 2
NAME STATE VERSION * Ubuntu-22.04 Running 2
⚠️ Se a versão aparecer como 1, converta para WSL2 com: wsl --set-version Ubuntu-22.04 2
03
Abrir o terminal Ubuntu no WSL2
Busque "Ubuntu" no menu Iniciar e abra. Na primeira vez, ele pedirá para criar um nome de usuário e senha (use algo simples, como aluno / bigdata). A partir de agora, todos os comandos são idênticos ao Ubuntu 22.04 na VM.
04
Atualizar o sistema WSL
Os mesmos comandos do Ubuntu VM funcionam aqui. Atualize os pacotes para garantir compatibilidade com o Hadoop.
bash — WSL2 Ubuntu 22.04
# Idêntico ao Ubuntu VM — o WSL2 é um Ubuntu completo! $ sudo apt update && sudo apt upgrade -y $ sudo apt install -y curl wget git htop net-tools vim
05
Diferenças importantes: WSL2 vs VM
No WSL2, há algumas diferenças de configuração que você precisará ter em mente ao instalar o Hadoop na próxima semana.
Situação Ubuntu VM (VirtualBox) WSL2 Ubuntu
Endereço IP Fixo ou dinâmico (192.168.x.x) Muda a cada reinício do Windows
Acesso ao HDFS Web UI http://localhost:9870 direto Funciona pelo navegador Windows normalmente
Arquivos Windows Precisa de pastas compartilhadas Acessível em /mnt/c/, /mnt/d/ etc.
Performance Ligeiramente melhor para I/O Excelente para uso geral
Recomendado para Máquinas com 16 GB+ de RAM Máquinas com 8-12 GB de RAM
