💡O que e MapReduce — entenda em 2 minutos

MapReduce e um modelo de programacao criado pelo Google em 2004 para processar grandes volumes de dados em paralelo em centenas de maquinas. O Hadoop implementa esse modelo — voce escreve apenas duas funcoes (Map e Reduce) e o framework cuida do resto: dividir os dados, distribuir para os nos, coletar os resultados.

💬 Analogia: Contar palavras em 1.000 livros. Voce distribui 50 livros para 20 amigos (Map). Cada amigo conta palavras e entrega uma lista: "hadoop: 30, spark: 15...". Voce soma as contagens de todos (Reduce). Pronto — isso e MapReduce.

Pipeline completo do MapReduce:

📂
INPUT
HDFS divide o arquivo em blocos e distribui para os nos
→
🗺
MAP
Cada Mapper processa um bloco e emite pares (chave, valor)
→
🔄
SHUFFLE & SORT
Agrupa valores com mesma chave — automatico!
→
⚙
REDUCE
Processa cada grupo e gera o resultado final
→
💾
OUTPUT
Resultado salvo no HDFS ou disco
🧠 Quiz 1 — Qual fase e responsavel por agrupar todos os valores com a mesma chave antes de envia-los ao Reducer?
✅ Correto! +60 XP. O Shuffle & Sort e automatico — o Hadoop faz isso sem voce programar nada. Garante que todos os ("hadoop", 1) de diferentes Mappers chegam ao mesmo Reducer.
❌ O Shuffle & Sort e a fase intermediaria automatica. O Mapper emite pares sem ordem; o Shuffle garante que a mesma chave vai sempre para o mesmo Reducer.
🔬WordCount — codigo Python explicado linha a linhaPython + mrjob

Usaremos Python + mrjob — uma biblioteca que permite escrever MapReduce em Python e rodar no Colab ou Cloud Shell sem instalar Hadoop. Mesma logica, sem burocracia de Java.

📌 Por que mrjob e nao Java? MapReduce em Java exige 80+ linhas de codigo repetitivo. Em Python com mrjob sao 12 linhas — voce foca no conceito que importa.
wordcount.py — codigo completo comentado 
from mrjob.job import MRJob   # importa a biblioteca mrjob
import re                        # para extrair palavras sem pontuacao

class WordCount(MRJob):

    # ---------------------------------------------------
    # FASE MAP
    # Chamada uma vez para cada LINHA do arquivo
    # _ = numero da linha (ignoramos, nao precisamos)
    # line = conteudo da linha ex: "big data big"
    # Emite: par (palavra, 1) para cada palavra
    # ---------------------------------------------------
    def mapper(self, _, line):
        palavras = re.findall(r'\w+', line.lower())
        for palavra in palavras:
            yield palavra, 1    # emite ("hadoop",1), ("spark",1), ("big",1)...

    # ---------------------------------------------------
    # FASE REDUCE
    # O Shuffle JA agrupou: ("big", [1, 1, 1])
    # palavra = chave (ex: "big")
    # contagens = iterador de valores [1, 1, 1]
    # Emite: (palavra, total)
    # ---------------------------------------------------
    def reducer(self, palavra, contagens):
        yield palavra, sum(contagens)   # ex: sum([1,1,1]) = 3

if __name__ == '__main__':
    WordCount.run()   # executa o job MapReduce

O que acontece internamente com "big data big":

trace de execucao passo a passo
📂 INPUT:           linha = "big data big"

🗺 MAPPER emite:    ("big",  1)   <-- 1a ocorrencia
                   ("data", 1)
                   ("big",  1)   <-- 2a ocorrencia (nao soma, so emite!)

🔄 SHUFFLE agrupa:  "big"  --> [1, 1]    (automatico, voce nao programa isso)
                   "data" --> [1]

⚙ REDUCER soma:   "big"  --> sum([1, 1]) = 2
                   "data" --> sum([1])    = 1

💾 OUTPUT:  "big"   2
         "data"  1
🧠 Quiz 2 — O Mapper recebe a linha "hadoop spark hadoop". Quantas vezes ele emite a chave "hadoop"?
✅ +60 XP! O Mapper nao e "inteligente" — ele emite (palavra, 1) para CADA palavra. "hadoop spark hadoop" vira 3 pares. O Shuffle e quem vai agrupar. Isso e o que permite o paralelismo: cada no processa sem depender dos outros.
❌ O Mapper emite 1 par por palavra encontrada, sem agrupar. "hadoop spark hadoop" vira ("hadoop",1), ("spark",1), ("hadoop",1). O Shuffle faz o agrupamento posterior.

Logica: split() divide a linha por espaco, pegamos o indice 2 (ERROR/WARN/INFO), emitimos (nivel, 1):
loganalyzer.py — solucao completa
from mrjob.job import MRJob

class LogAnalyzer(MRJob):

    def mapper(self, _, line):
        partes = line.split()           # divide a linha por espaco
        if len(partes) >= 3:             # garante que a linha e valida
            nivel = partes[2]            # 3a palavra = ERROR, WARN ou INFO
            yield nivel, 1              # emite ("ERROR",1), ("INFO",1)...

    def reducer(self, nivel, contagens):
        yield nivel, sum(contagens)    # soma: ERROR->4, INFO->5, WARN->3

if __name__ == '__main__':
    LogAnalyzer.run()

DESAFIO EXTRA — Listar apenas as mensagens de ERROR
Modifique o Mapper para filtrar apenas ERRORs e usar a mensagem como chave:
loganalyz_erros.py
from mrjob.job import MRJob

class LogErrors(MRJob):

    def mapper(self, _, line):
        partes = line.split()
        if len(partes) >= 4 and partes[2] == "ERROR":
            mensagem = " ".join(partes[3:])  # captura a mensagem de erro
            yield mensagem, 1

    def reducer(self, msg, counts):
        yield msg, sum(counts)

if __name__ == '__main__':
    LogErrors.run()
