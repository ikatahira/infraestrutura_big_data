1. Ementa

Conceitos fundamentais de Big Data. Características das tecnologias de Big Data: volume, velocidade, variedade, veracidade e valor (5Vs). Arquiteturas de sistemas distribuídos. Ecossistema Hadoop: HDFS, MapReduce, YARN. Processamento distribuído com Apache Spark. Bancos de dados NoSQL: orientados a documentos, colunas, grafos e chave-valor. Armazenamento e processamento de dados em nuvem. Data Lakes e Data Warehouses modernos. Ferramentas de ingestão e ETL para Big Data. Streaming de dados em tempo real. Conceitos de Data Mesh e Data Fabric. Governança de dados em ambientes Big Data. Aspectos de segurança e privacidade em infraestruturas de dados. Monitoramento e otimização de performance. Casos práticos de implementação de infraestrutura para Big Data.

2. Objetivos

2.1 Objetivo Geral

Capacitar os alunos a projetar, implementar e gerenciar infraestruturas escaláveis para armazenamento, processamento e análise de grandes volumes de dados, utilizando tecnologias modernas de Big Data e computação distribuída, preparando-os para atuar como cientistas de dados e engenheiros de dados em ambientes corporativos.

2.2 Objetivos Específicos

  • Compreender os fundamentos de sistemas distribuídos e processamento paralelo de dados
  • Implementar e configurar clusters Hadoop para processamento distribuído
  • Desenvolver aplicações de processamento de dados usando Apache Spark
  • Projetar e implementar soluções com bancos de dados NoSQL para diferentes tipos de dados
  • Utilizar serviços de nuvem para armazenamento e processamento de Big Data
  • Criar pipelines de ingestão e transformação de dados (ETL) em larga escala
  • Implementar arquiteturas de Data Lake e compreender suas diferenças em relação a Data Warehouses
  • Desenvolver soluções de streaming para processamento de dados em tempo real
  • Aplicar conceitos de governança, segurança e privacidade em ambientes Big Data
  • Monitorar e otimizar a performance de infraestruturas de dados distribuídos

3. Competências e Habilidades a Desenvolver

  • Projetar arquiteturas escaláveis para armazenamento e processamento de grandes volumes de dados
  • Configurar e administrar clusters de Big Data utilizando Hadoop e Spark
  • Selecionar e implementar bancos de dados NoSQL adequados para diferentes cenários de negócio
  • Desenvolver pipelines de dados robustos e eficientes usando ferramentas modernas de ETL
  • Implementar soluções de processamento em tempo real utilizando tecnologias de streaming
  • Utilizar serviços de computação em nuvem para Big Data (AWS, Azure, Google Cloud)
  • Aplicar boas práticas de governança e segurança em ambientes de dados distribuídos
  • Otimizar consultas e processos para melhorar a performance de sistemas Big Data
  • Trabalhar de forma colaborativa em projetos de infraestrutura de dados complexos
  • Comunicar decisões técnicas de forma clara para equipes multidisciplinares

6B. Laboratório IoT para Big Data - Práticas Hands-On

🔌 Infraestrutura de Rede e IoT Disponível

O laboratório conta com os seguintes equipamentos:

  • Dispositivos IoT:

    • ESP32 DevKit (WiFi/Bluetooth integrado)

🎯 Práticas Integradas IoT + Big Data

Prática 1: Rede de Sensores IoT em Tempo Real (Semanas 16-17)

Objetivo: Criar uma infraestrutura completa de coleta, transmissão e processamento de dados de sensores em tempo real, simulando um ambiente de Indústria 4.0.

Componentes:

  • Camada de Sensores: ESP32 + sensores (temperatura, umidade, movimento)
  • Protocolo de Comunicação: MQTT ou HTTP REST
  • Message Broker: Apache Kafka (recebe dados dos sensores)
  • Processamento: Spark Streaming (análise em tempo real)
  • Armazenamento: HDFS + MongoDB (histórico + dados atuais)
  • Visualização: Grafana (dashboard em tempo real)

Roteiro da Prática:

  1. Setup da Rede Física:
    • Conectar ESP32s à rede WiFi local
    • Organizar cabeamento no patch panel
    • Configurar switch para segmentação de rede (IoT VLAN)
  2. Programação dos Sensores:
    • Código Arduino/ESP32 para leitura de sensores (C++)
    • Envio de dados via MQTT para broker (Mosquitto ou HiveMQ)
    • Formato JSON: {sensor_id, timestamp, temperatura, umidade, movimento}
  3. Configuração do Pipeline:
    • Kafka Topic: iot-sensors-data
    • Kafka Connect MQTT Source Connector
    • Spark Streaming: consumir do Kafka, processar e detectar anomalias
    • Persistência dual: HDFS (histórico) + MongoDB (real-time)
  4. Análises em Tempo Real:
    • Detecção de valores fora do padrão (temperatura > 30°C)
    • Agregações por janelas de tempo (média/min/max por minuto)
    • Correlação entre sensores (movimento + mudança de temperatura)
  5. Dashboard e Alertas:
    • Grafana conectado ao MongoDB
    • Gráficos de linha temporal por sensor
    • Alertas configurados (Slack/Email quando anomalia detectada)

💡 Aprendizados: Arquitetura end-to-end IoT + Big Data, protocolos de comunicação, processamento streaming, análise em tempo real

Prática 2: Data Lake de Dados IoT (Semanas 12-13)

Objetivo: Construir um Data Lake multi-camadas para armazenar e processar histórico de dados de sensores IoT.

Arquitetura do Data Lake:

  • Raw Zone (Bronze): Dados brutos dos sensores (JSON, Parquet)
  • Curated Zone (Silver): Dados limpos e padronizados
  • Trusted Zone (Gold): Agregações e métricas de negócio

Atividades:

  1. Coletar dados de 5+ sensores por 1 semana (24/7)
  2. Armazenar em AWS S3 ou HDFS (zona raw)
  3. ETL com PySpark: limpeza, remoção de outliers, preenchimento de gaps
  4. Análises:
    • Padrões de temperatura por hora do dia
    • Correlação entre sensores de diferentes salas
    • Previsão de próxima leitura (série temporal)
  5. Catálogo de metadados (AWS Glue ou Apache Atlas)

Prática 3: Monitoramento de Infraestrutura (Semana 19)

Objetivo: Implementar monitoramento completo da infraestrutura IoT + Big Data.

Stack de Monitoramento:

  • Prometheus: Coleta de métricas (CPU, memória, rede dos ESP32 e servidores)
  • Node Exporter: Métricas de sistema dos servidores
  • Kafka Exporter: Métricas do Kafka (lag, throughput)
  • Grafana: Dashboards de infraestrutura + aplicação
  • Alertmanager: Alertas quando sensores param de reportar ou cluster degrada

🎯 Desafio Prático: Simular falha de sensor (desconectar ESP32) e observar como o sistema detecta e alerta. Medir latência fim-a-fim (sensor → visualização).

📋 Casos de Uso Simulados

  • Smart Building: Monitoramento de salas de aula (temperatura, ocupação, luminosidade)
  • Indústria 4.0: Sensores em linha de produção fictícia (temperatura de máquinas, vibração)
  • Agricultura Inteligente: Monitoramento de estufa (temperatura, umidade do solo, luz)
  • Logística: Rastreamento de condições ambientais durante transporte simulado
💻 Tecnologias Utilizadas nas Práticas IoT:
• Hardware: Arduino Uno, ESP32, DHT22, PIR, LDR, HC-SR04
• Programação: Arduino IDE (C++), Python (MicroPython para ESP32)
• Protocolos: MQTT (Mosquitto), HTTP/REST
• Big Data Stack: Kafka, Spark Streaming, HDFS, MongoDB
• Visualização: Grafana, Kibana
• Cloud (opcional): AWS IoT Core, Azure IoT Hub
• Monitoramento: Prometheus, Node Exporter, Grafana

7. Avaliação

7.1 Instrumentos de Avaliação

📝 Avaliação Teórica 1 (AT1) - Semana 9

Conteúdo: Fundamentos de Big Data, Hadoop, Spark e NoSQL
Formato: Prova individual escrita
Duração: 2 horas
Peso: 20%

💻 Atividades Práticas Laboratoriais (APL)

Conteúdo: Exercícios práticos semanais em laboratório
Formato: Implementações individuais ou em dupla
Quantidade: 8-10 práticas ao longo do semestre
Peso: 30%

📊 Projeto Integrador (PI) - Desenvolvimento ao longo do semestre

Conteúdo: Projeto completo de infraestrutura Big Data
Formato: Trabalho em equipe (3-4 alunos)
Entregas:
  • Proposta e arquitetura (Semana 5) - 10 pontos
  • Checkpoints de desenvolvimento (Semanas 10, 15) - 20 pontos
  • Entrega final e apresentação (Semana 20) - 70 pontos
Peso: 30%

📋 Avaliação Teórico-Prática Final (ATPF) - Semana 19

Conteúdo: Todo o conteúdo da disciplina
Formato: Prova com questões teóricas e resolução de problemas práticos
Duração: 3 horas
Peso: 20%

7.2 Critérios de Avaliação

  • Compreensão dos conceitos teóricos de Big Data e sistemas distribuídos
  • Capacidade de implementar soluções práticas com as tecnologias estudadas
  • Qualidade do código: organização, documentação e boas práticas
  • Adequação da arquitetura proposta aos requisitos do problema
  • Capacidade de otimização e troubleshooting
  • Trabalho em equipe e divisão de responsabilidades
  • Clareza na documentação técnica e apresentação de resultados
  • Criatividade e inovação nas soluções propostas
