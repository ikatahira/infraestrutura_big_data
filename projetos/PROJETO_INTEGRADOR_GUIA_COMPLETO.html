🔄 Fluxo de Dados Completo

  1. ESP32 lê DHT22: A cada 5 segundos, temperatura e umidade são lidas
  2. Publica MQTT: Dados em JSON são enviados para tópico MQTT "temp_topic"
  3. Bridge intercepta: Python script recebe do MQTT e encaminha para Kafka
  4. Kafka buffering: Mensagens ficam em fila no tópico "temp-readings"
  5. Spark consome: Streaming job processa dados em micro-batches (2 segundos)
  6. Validação: Remove leituras inválidas (fora de -50 a 60°C)
  7. Agregação: Calcula média móvel por sensor a cada minuto
  8. Detecção: Identifica alertas (temp > 40°C ou < 0°C)
  9. Persistência: Grava no MongoDB (raw + aggregated + alerts)
  10. Dashboard: Flask busca dados do MongoDB e exibe gráficos
  11. Auto-refresh: Página atualiza sozinha a cada 5 segundos
