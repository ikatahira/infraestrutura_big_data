📚 Sobre a Disciplina

Bem-vindo à disciplina de Infraestrutura para Big Data! Este curso aborda as principais tecnologias e práticas para construção de pipelines de dados em larga escala, desde a ingestão até a visualização.

🎯 O que você vai aprender:
• Ecossistema Hadoop (HDFS, MapReduce, YARN)
• Apache Spark para processamento distribuído
• Bancos de dados NoSQL (MongoDB, Cassandra)
• Streaming com Apache Kafka
• Cloud Computing com AWS (S3, EMR, Redshift)
• IoT e integração com Big Data
• Data Lakes e Data Warehousing
• Visualização de Dados e Machine Learning distribuído

📖 Como usar este material:

  • Semanas: Contêm o conteúdo teórico, vídeos, materiais e atividades práticas
  • Guias: Fornecem exercícios detalhados com rubricas de avaliação e soluções comentadas
  • Projeto Integrador: Desenvolvido ao longo do semestre (Semanas 10, 19 e 20)

Artigo Científico em Grupo — Big Data com Apache Hadoop
Grupos de 1 a 4 pessoas · Entrega ao final do período definido pelo professor
Com base nas práticas realizadas nas semanas 01, 02 e 03, cada grupo produzirá um artigo científico completo documentando a implantação e análise de uma infraestrutura Big Data com Apache Hadoop HDFS em ambiente Linux. O guia abaixo orienta todo o processo, incluindo o modelo e o artigo de referência para download.
🧭 Guia: Como Escrever o Artigo
🧩 Organização dos Grupos
Grupos de 1 a 4 pessoas. Cada grupo forma um mini time de pesquisa com papéis definidos abaixo. Todos participam de tudo, mas cada integrante responde por uma parte.
👨‍💻
1 · Infraestrutura
DevOps / SysAdmin
  • Instala o Hadoop
  • Configura o ambiente
  • Resolve erros
🗄️
2 · Engenheiro de Dados
Data Engineer
  • Executa operações HDFS
  • Trabalha com datasets
  • Organiza os testes
📊
3 · Analista / Experimentação
Data Analyst
  • Executa o MapReduce
  • Coleta os resultados
  • Gera tabelas e análises
✍️
4 · Redator Científico
Scientific Writer
  • Escreve o artigo
  • Padroniza ABNT/FATEC
  • Organiza referências
💡 Grupos menores: Em grupos de 1 a 3 pessoas, cada integrante acumula mais de um papel. Todos os papéis precisam estar cobertos no artigo final.
