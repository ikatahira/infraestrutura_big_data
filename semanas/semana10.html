🍃 MongoDB — Banco Orientado a Documentos
MongoDB é o banco de documentos mais usado do mercado — guarda dados em BSON (uma versão binária do JSON que você já modelou na Semana 09).

Coleção — equivalente a uma "tabela", mas sem exigir que todos os documentos tenham os mesmos campos.

Documento — equivalente a uma "linha", mas podendo ter campos aninhados e arrays (como o exemplo de avaliações que você já viu).

_id — todo documento no MongoDB tem um identificador único automático, gerado na inserção.

Quando usar MongoDB: quando seus dados têm estrutura flexível/variável, e você precisa de consultas ricas (filtros, agregações) — não só busca por chave simples.

📊 Cassandra — Banco Colunar Distribuído (Comparativo)
Cassandra resolve um problema diferente do MongoDB: escrita massiva e contínua, distribuída por muitos nós, sem um ponto único de falha.

Column-family — dados organizados por colunas (não linhas), otimizados para escrever e ler colunas específicas rapidamente em grande volume — muito usado para séries temporais e logs (ex: dados de sensores IoT, que você vai ver mais adiante no curso).

Sem nó master — diferente do HDFS (que tem 1 NameNode central) ou do MongoDB (que tem réplica primária), o Cassandra é peer-to-peer: todos os nós são iguais, não existe ponto único de falha. Prioriza disponibilidade sobre consistência imediata no Teorema CAP (é AP).

Vamos instalar o MongoDB de verdade e inserir o documento que você modelou na Semana 09.
01
Instalar o MongoDB no Ubuntu
No terminal da sua VM (Semana 01):
bash
wget -qO - https://www.mongodb.org/static/pgp/server-6.0.asc | sudo apt-key add - echo "deb [ arch=amd64 ] https://repo.mongodb.org/apt/ubuntu jammy/mongodb-org/6.0 multiverse" | sudo tee /etc/apt/sources.list.d/mongodb-org-6.0.list sudo apt update sudo apt install -y mongodb-org sudo systemctl start mongod sudo systemctl status mongod
02
Abrir o shell do MongoDB
Conecte no banco local que acabou de iniciar:
bash
mongosh
03
Inserir seu documento da Semana 09
Dentro do mongosh:
javascript
use bigdata_semana10 db.vendas.insertOne({ produto: "Notebook", categoria: "Eletrônicos", preco: 3500.00, quantidade: 2, avaliacoes: [{nota: 5, comentario: "Ótimo produto"}] })
04
Consultar os dados inseridos
Use find() para consultar, similar a um SELECT:
javascript
db.vendas.find() db.vendas.find({categoria: "Eletrônicos"}) db.vendas.find({preco: {$gt: 1000}})
