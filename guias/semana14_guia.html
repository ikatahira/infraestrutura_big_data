Você lembra da aula passada?

Na última aula, construímos com as próprias mãos o cabo de rede padrão T568B — crimpamos os fios no conector RJ-45 seguindo a sequência correta de cores e, em seguida, testamos a continuidade de cada par utilizando o testador de cabo de rede. 01 · O Conceito

Sensor → Dado Bruto → Informação

Antes de falarmos em Spark, Hadoop ou pipelines, precisamos entender onde nasce o dado. Tudo começa com um sensor físico capturando o mundo real.

🏢

O Cenário: Data Center

Imagine um rack de servidores em um Data Center corporativo. Por segurança, qualquer abertura de porta deve ser registrada com timestamp para auditoria e conformidade (LGPD, SOX, ISO 27001).

💡

O Sensor: LDR

O LDR (Light Dependent Resistor) é nossa câmera de segurança simplificada. Quando a porta do rack é aberta, a luz incide no sensor — e o Arduino registra esse evento instantaneamente.

📋

O Produto: Log Estruturado

O resultado é um log em formato CSV com ID, timestamp, valor bruto e status processado — exatamente o tipo de arquivo que sistemas de Big Data ingerem e analisam.

02 · Circuito

Montagem do Divisor de Tensão

O LDR não entrega um valor diretamente — ele muda sua resistência. Precisamos de um divisor de tensão para converter essa resistência em uma tensão legível pelo Arduino.

Conexões passo a passo

  • 5V
    Arduino 5V → Perna 1 do LDR
    Fornece tensão de referência ao circuito. O LDR receberá toda a corrente nesta perna.
  • A0
    Perna 2 do LDR → Pino A0 do Arduino
    O ponto de leitura. É aqui que o Arduino "escuta" a tensão que varia conforme a luz.
  • GND
    Resistor 10kΩ: Pino A0 → GND
    Fecha o circuito e cria o divisor de tensão. Sem ele, a leitura fica instável (flutuando).
⚡

Por que o Divisor de Tensão?

O Arduino só lê tensões (0 a 5V), mas o LDR muda sua resistência com a luz. O resistor de 10kΩ forma um par com o LDR: quando há luz, o LDR tem baixa resistência → maior tensão em A0 → valor próximo de 1023. No escuro, alta resistência → tensão menor → valor próximo de 0. Isso é a conversão analógico-digital (ADC) — o primeiro passo da telemetria.

🎨 Como identificar o resistor de 10kΩ pelas faixas coloridas?

Todo resistor tem um código de cores padronizado internacionalmente. Cada faixa representa um dígito, um multiplicador ou a tolerância. Veja como ler o seu resistor de 10kΩ:

🧩 Conheça os Componentes

Antes de montar, identifique cada peça na bancada. Veja como cada uma se parece fisicamente:

Arduino Uno

Microcontrolador baseado no ATmega328P. Possui 14 pinos digitais, 6 pinos analógicos (A0–A5), e se conecta ao computador via USB. É o "cérebro" do projeto.

Microcontrolador

LDR (Fotoresistor)

Light Dependent Resistor. A resistência varia com a luz: no escuro ~1MΩ, com luz intensa ~100Ω. Reconhecível pelo corpo redondo dourado com trilha em espiral (CdS) visível.

Sensor Analógico

Resistor 10kΩ

Componente passivo que limita a corrente. Identificado pelas 4 faixas: Marrom (1), Preto (0), Laranja (×1000), Dourado (±5%) = 10.000Ω.

Componente Passivo

Protoboard

Placa de prototipagem sem solda. Furos ligados em colunas verticais (área central) e trilhas horizontais nos barramentos laterais + e −. Permite montar e desmontar circuitos facilmente.

02.5 · Arduino IDE

Configurando o Arduino IDE

Antes de digitar uma linha de código, precisamos preparar o ambiente de desenvolvimento. O Arduino IDE é o software que permite escrever, compilar e enviar programas para a placa. Siga cada passo com atenção.

1

Abra o Arduino IDE

Localize o atalho na área de trabalho ou no menu iniciar e abra o programa. Você verá a tela principal com o editor de código, os botões de Verificar (✓) e Carregar (→) no topo.

2

Conecte o Arduino Uno ao computador via USB

Use o cabo USB tipo A–B (o mesmo de impressoras antigas) para conectar o Arduino Uno à porta USB do computador. O LED verde de alimentação da placa deve acender imediatamente.

🔌 Atenção: Nunca conecte ou desconecte componentes no protoboard enquanto o Arduino estiver ligado via USB. Sempre desconecte o USB antes de mudar o circuito para evitar curto-circuito.

Selecione a placa: Arduino Uno

No menu superior, clique em Ferramentas → Placa → Arduino AVR Boards → Arduino Uno. Isso instrui o compilador a gerar código para o microcontrolador correto (ATmega328P).

03 · O Código

Gerando Logs Profissionais

O código abaixo não apenas lê o sensor — ele o transforma em um log estruturado em CSV, pronto para ser ingerido por sistemas de Big Data.

monitoramento_rack.ino C++ / Arduino 
// ──────────────────────────────────────────────────────────
// SISTEMA DE MONITORAMENTO DE ATIVOS — TELEMETRIA COM LDR
// Curso de Ciência de Dados — Módulo 1
// ──────────────────────────────────────────────────────────

// Definição do pino analógico
const int pinoLDR = A0;
int luminosidade = 0;

void setup() {
  // Inicializa a Serial com 9600 bps
  Serial.begin(9600);
  Serial.println("--- INICIANDO SISTEMA DE MONITORAMENTO DE ATIVOS ---");
  Serial.println("LOG_ID, TIMESTAMP_MS, LUMINOSITY_VALUE, STATUS");
}

void loop() {
  // Lê o valor do LDR (0 a 1023)
  luminosidade = analogRead(pinoLDR);

  // Define um status baseado no limiar (threshold)
  String status = (luminosidade > 600) ?
    "ALERTA: LUZ ACESA" : "NORMAL";

  // Gera a linha de log separada por vírgulas (CSV)
  // Facilita a importação futura em sistemas de Big Data
  Serial.print(millis() / 1000);  // Contador de segundos
  Serial.print(", ");
  Serial.print(millis());         // Timestamp em ms
  Serial.print(", ");
  Serial.print(luminosidade);     // O dado bruto (raw data)
  Serial.print(", ");
  Serial.println(status);         // O dado processado (insight)

  delay(1000);  // Taxa de amostragem: 1 dado por segundo
}
1

Cabeçalho CSV

O setup() imprime o cabeçalho uma única vez. Todo arquivo CSV precisa de um cabeçalho para que ferramentas como Pandas e Spark saibam o nome de cada coluna.

2

Dado Bruto vs. Processado

luminosidade é o raw data (0–1023). status é o dado processado — já com significado de negócio. Em Data Science, sempre preservamos o dado bruto.

3

Timestamp em Millisegundos

millis() retorna o tempo desde o boot em ms. Em Big Data, o timestamp preciso é fundamental para juntar (JOIN) dados de múltiplas fontes por janela de tempo.

4

Taxa de Amostragem

O delay(1000) define 1 amostra/segundo. Mudar para delay(1) gera 1000 amostras/segundo — a base do Desafio 1 desta aula.

04 · Desafios

Discussão de Infraestrutura

Agora que o dado está sendo gerado, vamos pensar como engenheiros de dados. Cada desafio conecta o hardware físico a um problema real de Big Data.

D1

Volume — Quantos dados conseguimos gerar?

Big Data · Volume

Se esse sensor gerasse 1 dado a cada milissegundo (delay(1)), quantos registros teríamos em 1 dia? Nosso computador aguentaria salvar esse log em um arquivo .txt comum?

1.000 amostras/s × 60s × 60min × 24h =
86.400.000 linhas/dia ≈ 86,4 milhões de registros

Cada linha ≈ 40 bytes → ~3,4 GB por dia por sensor
Com 1.000 sensores em um Data Center → ~3,4 TB/dia
💡 É exatamente esse volume que justifica o uso de HDFS (sistema de arquivos distribuído do Hadoop) e Apache Kafka para ingestão em streaming. Um .txt local traria problemas de I/O, falta de espaço e impossibilidade de consultas paralelas.
D2

Qualidade — Como o Spark limpa dados ruidosos?

Spark · Qualidade

Passe a mão sobre o LDR rapidamente. Observe que o valor oscila bruscamente — picos de 700, 300, 800 em frações de segundo que não representam a realidade do ambiente.

// Exemplo de ruído observado no Serial Monitor:
12, 12001, 115, NORMAL
13, 13003, 742, ⚠ ALERTA: LUZ ACESA ← sombra da mão!
14, 14001, 118, NORMAL
15, 15002, 119, NORMAL

Esse pico de 742 é um falso positivo — um dado ruidoso. Em Apache Spark (que veremos no sábado), podemos aplicar:

🔧
Média Móvel (Moving Average): calcula a média dos últimos N valores. Picos isolados são "suavizados" sem gerar alertas falsos.

Filtro por Desvio Padrão: valores além de 2σ da média são descartados ou marcados como OUTLIER — isso é limpeza de dados em escala.
D3

Formatação — O Delimitador importa em Big Data?

ETL · Delimitador

Altere o código para usar ; ou | como separador em vez de vírgula. Substitua todas as ocorrências de ", " pelo novo delimitador.

// Versão com pipe ( | ) como delimitador:
Serial.print(" | "); // substitui ", "

// Saída resultante:
LOG_ID | TIMESTAMP_MS | LUMINOSITY_VALUE | STATUS
1 | 1000 | 112 | NORMAL
2 | 2001 | 134 | NORMAL

Por que isso importa? Em Big Data, ao importar um arquivo no Hive, Spark ou AWS Athena, você declara o delimitador explicitamente:

-- HiveQL:
ROW FORMAT DELIMITED
FIELDS TERMINATED BY '|'

# Python / Pandas:
df = pd.read_csv('log.txt', sep='|')
⚠️ Vírgula (,) é problemático quando os dados em si contêm vírgulas (ex: textos em português). O pipe (|) é mais seguro para dados textuais. TSV (\t) é padrão em muitos exports de banco de dados.
