CONECTAR E VALIDAR

Resultado esperado: link de 940+ Mbps com cabo correto, queda visível com cabo defeituoso.
04 Conceitos de Big Data

Hardware ↔ Big Data

Cada componente do servidor tem uma relação direta com os desafios dos 5 Vs do Big Data. Aqui mapeamos conceito a hardware real.

📈
Escalabilidade Vertical
O T110 II permite adicionar mais RAM (até 32GB) e discos SAS/SATA sem trocar o servidor. Demonstrar adicionando um pente de 8GB em sala e comparando o throughput do Spark antes e depois.
Scale-Up
🛡️
Tolerância a Falhas
Configurar RAID 1 na controladora PERC para simular a queima de um disco sem perda de dados. O aluno remove o HD com o sistema ligado (hot-swap SAS) e observa o array se reconstruindo.
Fault Tolerance
📍
Data Locality
Em Hadoop, o processamento ocorre no nó onde o dado reside. Discutir por que mover dados pela rede é 10× mais lento que processar localmente no SAS — e como o T110 exemplifica um nó de Data Node.
Hadoop HDFS
⚡
Memória ECC e Integridade
Um flip de bit em RAM comum pode corromper silenciosamente um modelo de ML. ECC detecta e corrige erros de 1 bit automaticamente. Essencial para jobs Spark que rodam por horas — sem ECC, o resultado pode estar errado sem nenhum erro visível.
Data Integrity
🔗
Network Bonding (LACP)
Com as 2 interfaces Gigabit do T110 configuradas em modo bonding (LACP), o throughput sobe para ~2Gbps. Demonstrar com o iperf3 antes e depois da configuração do bond0 no Linux.
Link Aggregation
🐳
Virtualização com Docker
Instalar Docker no T110 e criar containers de Jupyter + Spark. Os alunos acessam via SSH e rodam análises em dados reais. O servidor atua como host de multi-tenant para toda a turma simultaneamente.

05 Armazenamento

RAID & Controladora PERC H200

A redundância é vital quando o volume de dados ultrapassa a segurança de um disco único. O PERC H200 é uma controladora hardware que libera a CPU do gerenciamento de paridade.

0
⚡ RAID 0 — Striping
Máxima Performance
Dados distribuídos entre 2+ discos. Leitura/escrita paralela. Nenhuma tolerância a falhas — se um disco falha, tudo é perdido. Usar apenas para scratch storage ou dados reproduzíveis.
1
🛡️ RAID 1 — Mirror
Segurança Total
Cópia espelhada entre 2 discos. Capacidade = 50% do total. Proteção máxima contra falha. Ideal para dados críticos onde velocidade não é o foco. O T110 suporta nativo.
5
⚖️ RAID 5 — Paridade
Equilíbrio Ideal
Paridade distribuída entre 3+ discos. Capacidade = N-1 discos. Sobrevive à falha de 1 disco. Melhor custo-benefício para servidores de Big Data em laboratório.
10
🚀 RAID 10 — Mirror+Stripe
Performance + Segurança
Combinação de RAID 1 + RAID 0. Requer 4+ discos. Capacidade = 50%. Alta leitura, boa escrita, tolera falhas múltiplas. Usado em produção real quando ambos os requisitos são críticos.
H2
🔧 PERC H200 — Hardware RAID
Controladora Dedicada
Processador LSI dedicado ao cálculo de paridade. Libera 100% da CPU para o Spark/Hadoop. Tem BBU (Battery Backup Unit) para não perder cache em caso de queda de energia.
SAS
💿 SAS vs SATA
Interface de Disco
SAS: 12Gbps, dual-port, MTBF superior, hot-swap nativo. SATA: 6Gbps, single-port, menor custo. O T110 suporta ambos via PERC H200. Para datasets brutos: SATA. Para banco de metadados: SAS.
06 Redes e Acesso Remoto

SSH, Switch &
Infraestrutura

Em Big Data, servidores raramente possuem monitor. O acesso é feito via Secure Shell (SSH). O switch gerenciável controla o tráfego entre os nós do cluster.

🔐 Acesso via SSH — Gerenciamento Headless
Secure Shell com autenticação por chave pública/privada (Ed25519)
# Conectar no servidor via SSH $ ssh usuario@192.168.1.100 # Copiar dataset para o servidor $ scp dataset.csv node01:/data/raw/ # Gerar par de chaves (mais seguro que senha) $ ssh-keygen -t ed25519 -C "fatec-lab" $ ssh-copy-id usuario@hadoop-master # Acessar sem senha (chave configurada) $ ssh hadoop-master Welcome to Ubuntu 22.04 LTS (Dell T110 II) Last login: Mon Apr 28 08:30:15 2026
Hostnames recomendados:
hadoop-master · spark-node01 · spark-node02

🔌 Patch Panel & Patch Cords
Interface passiva que protege as portas caras do switch
PATCH PANEL
Interface passiva — terminação permanente dos cabos horizontais (Cat6 das paredes). Protege as portas do switch do desgaste mecânico.
PATCH CORD
Cabos curtos e flexíveis para manobras rápidas entre o painel passivo e o switch ativo. Facilmente substituídos sem mover o cabeamento fixo.
💡 Dica do lab: O mini-rack 6U/9U organiza toda a infraestrutura em ambiente ventilado, protegido e com fluxo de ar correto. Ideal para o laboratório de Big Data com 1 switch + 2 servidores + patch panel.

07b Aceleração Computacional

Gráficos &
GPGPU

O slot PCIe x16 do T110 II permite upgrade para GPU profissional, transformando o servidor em plataforma de Machine Learning com aceleração CUDA.

🖥️
Gráficos Internos
Matrox® G200eW integrada com 8MB VRAM. Foco exclusivo em saída de console básica via VGA. Sem capacidade de renderização ou computação — apenas para configuração inicial headless.
🔌
Upgrade para GPU Profissional
O slot PCIe x16 permite instalar placas profissionais como NVIDIA Quadro (visualização) ou Tesla/A-series (computação). Transformando o T110 numa plataforma de treino de modelos de ML em escala de laboratório.
⚡
GPGPU com CUDA
Núcleos CUDA para processamento paralelo massivo. Uma GPU Tesla T4 tem 2560 CUDA cores — supera a CPU em tarefas de álgebra linear tensorial (backpropagation, product matrix). Essencial para treino de redes neurais.
